GitHub 토큰

이 화면은 저장소의 파일을 직접 고칩니다. 그러려면 쓰기 권한이 있는 토큰이 필요합니다.

  1. github.com/settings/personal-access-tokens 에서 Fine-grained token 생성
  2. Repository access → Only select repositories → jikchaa/yclb
  3. Permissions → Repository permissions → Contents: Read and write
  4. 만든 토큰을 아래에 붙여넣기
